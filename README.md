# rock-paper-scissors

My first project



Rock, Paper, Scissors —  Python Game



A lightweight, terminal-based implementation of the classic Rock, Paper, Scissors game built using Python 3. This project was developed to master fundamental control flow paradigms and random variable generations.



Core Programming Mechanics Covered

Control Flow Structures:\*\* Deep execution of nested `if/elif/else` logical matrices.

Algorithmic Randomization:\*\* Utilizing Python's built-in `random` module to simulate unbiased computer choices.

User Input Vetting:\*\* Implementing string normalization techniques (`.lower()`) to prevent user input syntax errors.



How to Run the Script

Ensure you have Python 3 installed on your operating system. Execute via your terminal:



bash

python rock\_paper\_scissors.py
